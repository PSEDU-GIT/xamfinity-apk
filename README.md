# 키오스크용 apk 설치 파일

키오스크용 태블릿에서 업데이트 관리할 때 사용.

firebase Remote Config에 current_version이 현재 버전보다 낮을 경우 자동으로 해당 파일로 업데이트를 진행한다.

firebase Remote Config에 **apk_url** 에 apk 파일 주소를 작성.
   
우측 Releases에 apk 파일을 업로드 한다.
